# 配信日和

公式ホロジュールの掲載枠と、追加した YouTube チャンネルの公開配信を日本時間で確認できる Web アプリです。配信は「配信中」「今後の配信」「過去の配信」に分かれます。

## 起動

### GitHub Codespaces

#### Mac・Windows で「配信日和を開く」

最初の一度だけ、次の準備をします。

1. 手元のパソコンに Node.js 24.5 以降、GitHub CLI (`gh`)、OpenSSH クライアントを用意し、このリポジトリをクローンします。[GitHub CLI のインストール](https://github.com/cli/cli#installation)
2. 手元で `gh auth login --hostname github.com --web --scopes codespace` を実行し、Codespace の所有アカウントで認証します。すでに認証済みなら `gh auth refresh --hostname github.com --scopes codespace` で権限を追加できます。認証情報は GitHub CLI が管理します。
3. 既存の Codespace 側にも最新のコードを取り込み、SSH 機能を有効にするため **Codespaces: Rebuild Container** を一度実行します。使っている Codespace の作業フォルダと配信日和の保存ファイルをそのまま使います。

以降は、手元のリポジトリ内にある **`配信日和を開く.command`**（Mac）または **`配信日和を開く.cmd`**（Windows）をダブルクリックします。ターミナルに起動状況が表示され、配信日和の応答を確認してから既定のブラウザが開きます。使っている間はターミナルを開いておきます。開いたままもう一度起動すると、その接続を使ってブラウザを開きます。

同じリポジトリに Codespace が複数ある場合や手元のポート 3000 が使用中の場合は、手元のリポジトリ直下に `.haishin-launch.json` を作れます。次の `codespace` には GitHub に表示される既存の Codespace の名前を指定します。`port` は省略できます。

```json
{
  "codespace": "your-codespace-name",
  "port": 3001
}
```

ターミナルからは `npm run codespaces:open` でも実行でき、必要に応じて `-- --codespace 名前 --port 3001` を付けられます。接続は手元のループバックアドレスに限られ、GitHub 側のポート公開設定は使いません。Codespaces の稼働時間と保存容量には通常の無料枠や予算設定が適用されます。[Codespaces の無料枠](https://docs.github.com/ja/codespaces/troubleshooting/troubleshooting-included-usage)

#### ブラウザ・スマートフォン

配信日和の画面下の「起動用 HTML をダウンロード」から、使用中の Codespace 専用の起動ファイルを保存できます。ファイル内の「配信日和を開く」で GitHub の起動画面へ進みます。サインインや再開の確認が出たら GitHub の画面で操作します。Codespace の起動時にサーバーが自動で立ち上がり、ポート自動転送時に配信日和をブラウザで開く設定です。アプリのタブが開かない場合は「アプリを直接開く」か、Codespaces の **Ports → 配信日和（3000）→ Open in Browser** を使います。対応ブラウザから `https://CODESPACE-NAME.github.dev/` をブックマークして開くこともできます。[GitHub の再開手順](https://docs.github.com/ja/codespaces/developing-in-a-codespace/opening-an-existing-codespace)

### Windows・macOS・Linux

Node.js 24.5 以降で、リポジトリのルートから実行します。追加のパッケージは不要です。

```sh
npm run open
```

サーバーが起動し、既定のブラウザで配信日和を開きます。Windows の PowerShell で `npm.ps1` の実行が制限されている場合は `npm.cmd run open` を使います。ブラウザを手動で開く場合は `npm start` で起動して `http://127.0.0.1:3000` にアクセスします。

ポートは `PORT` で変更できます。デフォルトはループバック接続です。クラウドのポート公開を利用する場合は `HOST=0.0.0.0 npm start` で起動できます。設定と履歴は同じサーバーを使う利用者で共有されます。

## 使い方

- アプリをすぐ開くには、画面下の「起動用 HTML をダウンロード」から起動ファイルを保存できます。Codespaces で使う場合と、手元で起動したアプリで使う場合の手順は上の「起動」を参照してください。
- 右上で「昨日」「今日」「明日」またはカレンダーから日付を選ぶと、その日の配信を日本時間で表示します。日付をまたぐライブは、配信中の各日と、終了時刻を確認できた範囲の日に表示します。「全日程」では配信を開始日ごとに一覧できます。
- 配信一覧、3Dライブ、MVの検索欄では、タイトルやチャンネル名のほか、`すいちゃん`、`ぺこーら`、`せんちょう` などの愛称やタレント名の読みでも検索できます。
- 通常のスケジュールにはライブ配信とそのアーカイブを表示します。YouTube の情報で配信かどうかを確認し、ショートや通常投稿を除外します。ページを開くと未取得のタイトルを YouTube で調べ、「更新」を押すと前回取得できなかったタイトルを再試行します。
- 「X」タブで公開リストを登録すると、そのタイムラインが表示されます。登録済みのタレント全員を名前・読み方・愛称・Xのユーザー名で検索し、本人の公開タイムラインに切り替えられます。`すいちゃん`、`こぼ`、`Suisei Hoshimachi` のように入力できます。
- 「3Dライブ」タブでは、ホロライブの女性メンバーによる生誕・周年記念などの3Dライブを確認できます。全日程から新しい順に40件を表示し、「さらに表示」で続きが見られます。日付やキーワードで全件から探せます。確認済みの公開アーカイブを初期収録し、今後はホロジュールの「ホロライブ」枠で3Dライブと判定できた配信を追加します。専用の履歴はホロジュールの掲載終了後も残ります。
- 自動判定にはホロジュールの掲載名と、リンク先から取得できる配信タイトルを使います。タイトルで判定できない枠は、「過去の配信を登録」の「3Dライブとして登録」から公開アーカイブを追加できます。
- 「MV」タブでは、新着順・再生回数順・急上昇順・メンバー順・高評価順を選べます。「すべて・オリジナル・カバー」の絞り込みは、日付やかな検索と組み合わせられます。メンバー順はメンバー名やグループ名の読みの五十音順です。画面には40件ずつ表示します。
- 急上昇順は、直近7日以内に日本時間で別の日に記録した再生回数の差が大きい順です。確認できた増加数や高評価数があるMVから表示します。曲の種類が未判定のMVは「すべて」で確認できます。
- MVの予定はホロジュールの「ホロライブ」枠を優先します。YouTube の公式チャンネルの新着から対象を補い、動画IDで重複を除いて保存します。既存の `YOUTUBE_API_KEY` がある場合は動画の詳細、公開再生回数、高評価数も更新します。キーがない場合は YouTube の公開フィードで確認できた新着を追加します。
- 「チャンネルを追加」に YouTube チャンネルの URL を入力します。例は `https://www.youtube.com/@NASA` です。
- 「チャンネル設定」からチャンネルを一覧から外せます。初期登録のタレント・公式チャンネルは非表示になり、設定から再表示できます。手動で追加したチャンネルは削除されます。
- 取得した配信は自動保存され、後日も配信日を選んで視聴リンクを開けます。取得元の一覧から外れ、予定日時が過ぎた枠は、終了を確認できるまで「アーカイブ未確認」と表示します。「チャンネル設定」で保存をオフにした場合、自動取得した過去の配信は、掲載終了後、終了から原則24時間で外れます。
- 「過去の配信を登録」で、配信日（日本時間）、表示中のチャンネル、公開ライブ配信アーカイブの HTTPS URL を入力できます。タイトルを省略すると、取得できた YouTube のタイトルを使います。登録した配信はカレンダーの該当日に表示されます。
- 複数の公開アーカイブは、UTF-8 の CSV ファイルで取り込めます。`channel` は表示中のチャンネルの名前（完全一致）または ID です。先頭行とデータ行を次の形式で記入します。

  ```csv
  date,channel,title,url
  2024-04-15,ときのそら,配信タイトル,https://www.youtube.com/watch?v=abcdefghijk
  ```

- サーバーの稼働中は約2分ごとに配信情報を取得します。通信に失敗した場合は画面にメッセージが出ます。
- 追加チャンネル、保存設定、取得した履歴は `.data/schedule.json`、追加したMVと取得済みの高評価数や再生回数の履歴は `.data/schedule-mv.json` に保存されます。`SCHEDULE_DATA_FILE` を指定すると、MVの保存ファイルも同じフォルダに置かれます。

## 配信データと通信

公式ホロジュールの「ホロライブ」枠から、女性メンバーやホロライブのユニットの予定を取得します。追加チャンネルは YouTube の公開配信が対象です。さかのぼれる範囲は各取得元の公開一覧に依存します。取得元への接続が制限されている環境では、`schedule.hololive.tv` と `www.youtube.com` への HTTPS 通信を許可してください。サムネイルには `i.ytimg.com` へのアクセスを使います。

初期のチャンネル一覧にはホロライブ公式YouTubeチャンネルと、JP・ID・EN・DEV_IS の女性タレントとアフィリエイトを収録しています。FUWAMOCO と holoAN room はそれぞれ共有チャンネル1件として表示します。名簿を更新するときは `src/data/hololive-roster.mjs` を編集してください。

公開ページからの取得には API キーが不要です。YouTube Data API v3 を利用する場合は、環境変数 `YOUTUBE_API_KEY` を設定し、`www.googleapis.com` への HTTPS 通信も許可してください。公開ページに接続できない場合、追加チャンネルの情報は API のアップロード一覧に含まれる配信に限られます。

### Xの公開リストを表示する

1. Xで公開リストを作り、見たいタレントを追加します。[Xのリスト作成手順](https://help.x.com/ja/using-x/x-lists)
2. `https://x.com/i/lists/…` の形式のURLをコピーし、「X」タブの登録欄に貼り付けて保存します。リスト1件を `.data/schedule.json` に保存し、同じサーバーで共有します。
3. タレントを検索して選ぶとその人の公開タイムラインを表示し、「登録リストに戻る」でリストの表示に戻せます。

投稿の表示には無料の公式埋め込みを使います。表示順や表示範囲はXが決めます。埋め込みが表示されないときはアプリ内の「Xで開く」リンクから確認できます。[X公式の埋め込み手順](https://help.x.com/ja/using-x/embed-x-feed)
